# حارس النار

نموذج أولي لبرنامج إنذار مبكر للحرائق في المناطق النائية. افتح `index.html` في أي متصفح، ثم اختر المنطقة وسرعة الرياح واضغط «تشغيل الوكيل» لمشاهدة تغيير تقييم الخطر والتوصية.

## الوكلاء

1. وكيل الاستشعار: يجمع بيانات الطقس، النقاط الحرارية وصور الأقمار الصناعية.
2. وكيل تقييم الخطر: يدمج الرياح والجفاف وسجل الحوادث ليعطي درجة 0–100.
3. وكيل الاستجابة: يحول الدرجة إلى توصية وتنبيه مخصص للدفاع المدني والمقيمين.

البيانات في النموذج محاكاة آمنة للعرض. في الإنتاج يمكن ربطها بـ NASA FIRMS وOpenWeather وخرائط Google أو Mapbox وقاعدة PostgreSQL.
